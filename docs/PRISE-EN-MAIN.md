# Première session avec Aegis

## Jouer avec le HUD et les sessions automatiques

Dans Réglages → Jeux, activez ou désactivez les sessions automatiques. Dans Affichage en jeu, choisissez le coin, la taille et l’opacité du HUD. Pour LoL, préférez Sans bordure ou Fenêtré. Le client seul ne lance pas de session : le processus de partie doit être présent. Dans Apparence, choisissez Français ou English, puis Enregistrer.

Les FPS ne sont pas affichés en direct dans le HUD. La capture PresentMon facultative donne des statistiques après arrêt. Consultez aussi le [guide illustré du site](https://zerionia.com/apps/aegis#installation).

## Retrouver une saccade

1. Ouvrir **Sessions**, donner un nom parlant : jeu, scène, résolution et réglages.
2. Laisser « Capteurs uniquement » pour commencer. Sélectionner un processus est facultatif et sert à PresentMon ; les capteurs fonctionnent aussi sans capture des présentations.
3. Démarrer la session, puis utiliser le PC normalement. Attendre la première mesure avant un marqueur.
4. Lors d’un ralentissement, presser **Ctrl+Alt+F8**. Si le raccourci est indisponible, utiliser le bouton de la fenêtre ou le menu de l’icône près de l’horloge.
5. Arrêter la session. Ouvrir **Dernier bilan** ou retrouver son nom dans la bibliothèque. Le marqueur situe un ressenti ; les mesures seules ne prouvent pas sa cause.

## Comparer un changement

Faire une première session, changer un seul réglage, puis recommencer la même scène pendant une durée comparable. Dans la bibliothèque, choisir deux sessions distinctes pour comparer leurs bilans. Garder les conditions dans le nom ou les annotations.

Une hausse de charge ou de température est un indice à examiner. Une valeur « Indisponible » ne signifie pas zéro. Les FPS et centiles ne sont proposés que si une capture réelle des présentations a réussi.

## Garder Aegis accessible

La réduction peut masquer l’app près de l’horloge ; un double-clic sur l’icône ou une nouvelle ouverture la ramène. La croix ferme l’app après sauvegarde. Le panneau compact s’ouvre depuis la barre latérale ou le menu de l’icône ; le plein écran exclusif peut le masquer.

Le démarrage avec Windows se choisit dans **Réglages → Au quotidien → Enregistrer**. Il reste désactivé à l’installation.

## Demander de l’aide

Depuis **Découvrir Zerionia**, créer un rapport support local, le relire puis le joindre manuellement à son message à **contact@zerionia.com**. Il contient des compteurs et informations de version, sans valeurs de capteurs, noms de sessions ni chemins.

Pour un bug reproductible, joindre les étapes, la version d’Aegis et ce qui était attendu sur [GitHub Issues](https://github.com/ZerionIA/aegis-pc/issues). Ne publier ni donnée privée ni journal contenant des chemins personnels.

## Mettre à jour

Aegis peut vérifier et télécharger les nouvelles releases GitHub hors session. L’installation demande confirmation. Un simple commit sur GitHub ne met pas les utilisateurs à jour. Les sessions restent dans le dossier de données après mise à jour ou désinstallation.
