# Sécurité

Bêta sans audit de sécurité indépendant complet. Signature Authenticode et mises à jour signées restent à mettre en place.

Utiliser le signalement privé GitHub si disponible ; sinon demander un canal privé dans une issue sans exposer de secret, donnée personnelle ou exploitation détaillée. Ne jamais joindre une base personnelle ou un audio privé.

Aegis ne demande pas de désactiver antivirus, Windows ou anti-cheat. Les empreintes permettent de comparer les fichiers, elles ne remplacent pas une signature numérique.
