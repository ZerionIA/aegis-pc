# Confidentialité

Aegis conserve mesures, sessions, marqueurs et réglages dans %LOCALAPPDATA%/AegisNext. Un journal local avec rotation peut contenir des chemins personnels ; il n'est pas transmis automatiquement. Aucun compte, publicité, analytique ou télémétrie distante n'est intégré.

Les exports et signalements GitHub sont volontaires : relire et anonymiser avant partage. Les téléchargements facultatifs contactent GitHub, Hugging Face, le registre Ollama et leurs infrastructures. Ils reçoivent les données réseau nécessaires, dont l'adresse IP, selon leurs politiques. La compilation contacte NuGet.

Le microphone s'active après clic. Un WAV temporaire est transcrit localement puis supprimé après transcription ou annulation ; une fermeture anormale peut empêcher son nettoyage. Aegis n'envoie aucun audio à un service de transcription. La lecture utilise les voix Windows installées.

Les modèles sont appelés en loopback. Désinstaller préserve les données. La suppression des sessions et composants est actuellement manuelle, application fermée. Aucun paiement n'est traité.

Contact : [dépôt](https://github.com/ZerionIA/aegis-pc). Ne pas publier de données personnelles dans une issue.
